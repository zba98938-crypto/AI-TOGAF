# 来源附件递归闭包

`close_skill_sources.py` 在全量检索记录之外，解析包内 Markdown 的图片和本地文档引用。
支持内联链接、参考式链接及 HTML 资源属性；到达共享文档后继续递归，循环引用不重复复制。
原生来源与附件保留原路径关系和字节，历史 Markdown 不为关闭断链而改写。
已记录的便携阅读派生件保留其已证明的相对链接。

历史附件必须经过迁移清单的身份、目标路径与 SHA-256 校验。
缺文件、未记录的历史附件、指纹冲突、越界、危险协议及文件或目录符号链接均阻断。
已封装的 source-tools 资产只有其先前来源指纹仍匹配时才可复用。
历史外部文献 URL 保留为文献，不在构建或查询中获取远程资源。

完整依赖图写入 `source-map.json`，`source_closure.py` 重新解析实际文档并核对整份图、
包内目标与指纹。文档对 `source-map.json` 的自身引用只记录位置和存在性；
整份清单由来源闭包执行记录在外部计算 SHA-256，避免自包含指纹循环。
封装、发布与独立目录解包复用同一全量门禁。

预冻结实跑 `output/project-stabilization-20261109/source-dependency-probe-04/` 修复了
220 条历史附件断链，核对 9,985 个依赖引用、4,356 个来源文件、6 个检索索引、
13,568 条记录及 524 个来源身份。历史正文指纹不变；移至独立目录并拒绝读取
原工程后通过。该目录属于主仓库的阶段证据，不作为未来修订版本的冻结验收。
独立审计发现并复测了共享文档后续缺文件、危险协议、参考式/HTML 图片以及
内部符号链接漏检；正式新增用例位于 `tests/test_source_dependencies.py`。

这些检查只证明来源可访问和字节一致；历史译文语义、完整规范能力、独立模型
复核、507 项评测及专业或组织签署分别验收。
