# 实施治理：分析方法

适用 ADM：G。以下为跨指南综合及项目生成约定。

## 分析路径

1. 明确实施范围和适用架构版本。
2. 约定各方责任与验收证据。
3. 逐项比较实施与架构要求。
4. 分析偏离风险及补救选项。
5. 记录真实决策与后续验证。

## 关键判断

架构合同是架构工作和实施之间的可审查约定；不能伪造签署或默认法律效力。合规结果至少区分满足、偏离、证据不足。例外要有适用期限和风险责任；自动检查只提供部分证据。

## 评审重点

每项结论可定位证据；未批准例外不写已接受；控制设计不等于运行有效；治理决策有决策者及日期来源。
