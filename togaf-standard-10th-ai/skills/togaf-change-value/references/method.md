# 变更与价值管理：分析方法

适用 ADM：H。以下为跨指南综合及项目生成约定。

## 分析路径

1. 比较承诺成果与实际观测。
2. 区分业务、技术、外部和治理变化。
3. 分析影响范围和紧迫度。
4. 提出维护、局部迭代或新周期选项。
5. 更新全景、请求与复评安排。

## 关键判断

收益监测要求指标基线、窗口、责任及可归因假设；没有观测不能称价值已经实现。变更请求处理具体变化，架构工作请求提出新的工作必要性，工作说明书才形成范围与交付约定。

## 评审重点

实际值与目标值独立；触发下一轮有理由；未决变更不覆盖已知基线；新工作保留审批状态。
