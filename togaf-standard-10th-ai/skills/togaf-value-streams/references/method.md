# 价值流分析：分析方法

适用 ADM：B E。以下为跨指南综合及项目生成约定。

## 分析路径

1. 确定触发方及其期望价值。
2. 定义开始结束边界。
3. 用进入退出条件和价值项界定阶段。
4. 逐阶段映射使能能力。
5. 识别价值断点、瓶颈及改进候选。

## 关键判断

阶段是价值增加的单位，不是作业步骤；同一能力可支撑多个阶段。价值链按主要和支持活动分析企业价值逻辑，价值流以利益相关者成果驱动，精益价值流偏重流动和浪费；按问题选择。嵌套只在明确约定时表达分解或实例组成。

## 评审重点

阶段有可验证退出条件；能力映射不暗示时间顺序；颜色不凭空产生绩效结论；子价值流与能力实例分别建模。
