# 方法来源与证据边界

本文为项目方法综合，不是标准原文。原始指南不随技能集复制；离线使用依靠以下方法摘要与制品规范。可公开访问的基础标准正文未取得，操作字段及矩阵代码均明确为项目约定。

## G152 · 将风险与安全融入 TOGAF® 企业架构

风险与安全贯穿 ADM，不是 D 阶段的附属清单。风险包括不确定性对目标的正向与负向影响。先识别业务价值、风险情景与风险责任，再选控制并跟踪残余风险；安全属性应进入需求及验证。不得凭空提供通用合规结论。

定位：第 3—5 章。原项目相对路径：`togaf-standard-10th-zh/G152e_将风险与安全融入TOGAF企业架构.md`。官方入口：https://www.opengroup.org/library/g152。原文指纹见 [sources.json](../sources.json)。

## 图表解释的使用

按 [图表索引](figure-index.json) 的 summary 搜索，再读取对应 misreadings 与 quality。图的颜色、虚线、包含与交叉均按该图图例解释。G248/fig3-1 为中等置信度的复杂元模型，无箭头线的方向依主动/被动标签判断；G233/fig6-3 的能力实例不是能力分解；G178/fig4-3 的列位置表达阶段使能关系，原图没有成熟度热力色。不能把 relations.json 中派生逆向导航关系作为额外事实。
