# BI 与分析演进规划

方法 ID：bi-transition-method。主责：togaf-information-data。来源：G238 §3。步骤与输出结构是本技能的操作约定。

## 输入

- 现有平台
- 目标需求
- 数据流与迁移约束

## 实际分析步骤

1. 对齐状态
2. 设计多过渡共存
3. 区分入站出站回写
4. 验证运营与迁移依赖

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- [BI 与分析演进架构](../capabilities/bi-transition-architecture.md)

- 参考目标平台不直接指定厂商

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
