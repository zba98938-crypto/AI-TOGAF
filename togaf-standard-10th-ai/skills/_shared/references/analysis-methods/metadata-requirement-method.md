# 元数据需求与范围分析

方法 ID：metadata-requirement-method。主责：togaf-information-data。来源：G234 §4.2–4.3。步骤与输出结构是本技能的操作约定。

## 输入

- 法规
- 用例
- 数据问题和数据集

## 实际分析步骤

1. 自上而下或自下而上引出需求
2. 定义类别质量
3. 限定资产范围
4. 形成概念逻辑模型

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- [元数据模型](../capabilities/metadata-model.md)

- 参考资产清单不是强制全选

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
