# 可持续性方案评审

方法 ID：sustainability-option-review。主责：togaf-artifact-review。来源：G242 §3.8–4。步骤与输出结构是本技能的操作约定。

## 输入

- 业务贡献
- 环境数据
- 措施与评价规则

## 实际分析步骤

1. 记录新增退役与净值
2. 比较措施
3. 保留权衡
4. 记录债务和复评

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- [可持续性架构评审画布](../capabilities/sustainability-review-canvas.md)

- 原图印刷矛盾保留证据，不静默改数

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
