# 能力定义与分解

方法 ID：capability-decomposition-method。主责：togaf-strategy-capabilities。来源：G211 §3。步骤与输出结构是本技能的操作约定。

## 输入

- 业务对象
- 结果
- 范围及既有能力

## 实际分析步骤

1. 稳定命名
2. 分同层粒度
3. 检验分解覆盖
4. 保持组织和实现独立

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- business-capabilities-catalog（见既有覆盖索引）

- 流程步骤不作为子能力

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
