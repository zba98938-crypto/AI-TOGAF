# 参考模型裁剪

方法 ID：reference-model-tailoring。主责：togaf-architecture-workbench。来源：G21D §1；G21H §6；G248 §2。步骤与输出结构是本技能的操作约定。

## 输入

- 本地范围
- 参考分类
- 职责与约束

## 实际分析步骤

1. 识别适用结构
2. 映射本地概念
3. 记录不适用与缺口
4. 定义后续验证

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- [政府参考模型裁剪](../capabilities/government-reference-tailoring.md)

- 参考分类不是项目实际组织或部署事实

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
