# 按变革画像逐项核查

主责：[实施治理](../../../togaf-implementation-governance/SKILL.md)。来源：G248 §3、§9 表9-1及§11 表11-1。制品：[变革画像治理检查清单](../capabilities/change-profile-governance-checklist.md)。

输入具体变革范围、Rapid/Functional/Robust画像、命名过渡、采用来源、检查证据和裁剪理由。先决定适用项，再逐项评审规划可实现性、实施符合性和价值结果。三类结果不得相互替代；项目没有证据时保持未评审，有冲突时保留争议及责任人。

确定性接口使用 `method_id: "change-profile-checklist"`，输入字段见 [完整原料到结果案例](../method-cases/change-profile-governance-review.md)。每次修改画像、过渡、回答或裁剪后重新运行。此方法没有权重、总分和默认合格线，输出不构成批准。
