# 微服务边界与价值分析

方法 ID：microservice-boundary-method。主责：togaf-application-architecture。来源：G21I §6–7。步骤与输出结构是本技能的操作约定。

## 输入

- 业务功能
- 质量目标
- 数据所有权与运营约束

## 实际分析步骤

1. 比较边界
2. 评价独立性和耦合
3. 定义技术指南
4. 记录服务价值与资源

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- [微服务应用分解方法](../capabilities/microservice-decomposition-method.md)

- 更多更小服务不自动提供价值

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
