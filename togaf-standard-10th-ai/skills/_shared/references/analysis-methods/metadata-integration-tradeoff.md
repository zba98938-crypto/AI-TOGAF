# 元数据集成与采集权衡

方法 ID：metadata-integration-tradeoff。主责：togaf-information-data。来源：G234 §4.3。步骤与输出结构是本技能的操作约定。

## 输入

- 权威源
- 社区
- 时效
- 安全和资源限制

## 实际分析步骤

1. 比较集中混合统一
2. 独立比较手工推送拉取
3. 定义协作契约
4. 评估代价

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- [元数据集成模型](../capabilities/metadata-integration-model.md)

- 组织模型和采集机制不能混为一维

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
