# 客户主数据身份与集成分析

方法 ID：mdm-identity-analysis。主责：togaf-information-data。来源：G21B §4–5、附录B。步骤与输出结构是本技能的操作约定。

## 输入

- 客户源记录
- 业务身份
- 权威与质量要求

## 实际分析步骤

1. 分析内核客户概念
2. 明确匹配合并
3. 选择集成风格
4. 定义交换和治理

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- [客户主数据模型](../capabilities/customer-mdm-model.md)

- 统一客户视图不是无条件合并所有记录

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
