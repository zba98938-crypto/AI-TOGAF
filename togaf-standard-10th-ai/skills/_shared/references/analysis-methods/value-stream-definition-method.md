# 价值流定义与能力使能

方法 ID：value-stream-definition-method。主责：togaf-value-streams。来源：G178 §3–4。步骤与输出结构是本技能的操作约定。

## 输入

- 受益者
- 触发
- 阶段和价值成果

## 实际分析步骤

1. 确定最终价值
2. 定义阶段进入退出
3. 关联使能能力
4. 识别阶段差距

每一步保留输入、转换与结果的追溯。先进行业务判断并记录理由，再把对象和关系写入模型；脚本只在已给出完整规则时计算。

## 输出与评审

- value-stream-map（见既有覆盖索引）

- 价值链与价值流用途和结构不同

记录阻断缺口；无明确规则不计算数值或形成确定结论。

修改分析时保留范围、模型版本和稳定 ID，并对输入变化重算或重评。评审分别核对事实证据、方法适用性、运算及结论，不能仅检查文件生成成功。
