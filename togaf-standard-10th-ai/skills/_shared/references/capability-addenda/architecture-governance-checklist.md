# 架构治理检查清单

目标能否批准，实施是否合理遵循目标且如何处理偏差？

依据：G184 §6.2；G186 §15.2.1表15-1、§15.2.2表15-2。源文提供方法与参考，字段和状态编码为项目操作规范。公开官方核验以覆盖索引为准。

## 必要输入与缺口

范围和五维语境；原始访谈/计划/测量及定位；授权角色和适用目标版本。逐项登记缺口；未知不等于否或零。缺授权、原口径、时点或关键证据时只能候选，不自动批准、通过或核算。

## 字段与语义

| 字段 | 含义 |
|---|---|
| name | 检查项名称 |
| subject | 受评对象及精确版本 |
| sequence | 来源规定的检查顺序 |
| question | 检查问题 |
| answer | yes/no/unknown/not-reached；后两者是项目缺口约定 |
| evidence_refs | 对应原料和模型/视图证据 |
| accountable_role | 责任角色及决策权 |
| next_action | 按本问题分支采取的动作 |
| result | 本案例整体结论；不代表真实批准 |
| source_variant | 使用的指南和差异说明 |

## 从原料到结论

1. 区分目标开发与实施变更两类治理对象
2. 锁定对象版本、上层约束、原价值口径和角色权利
3. 按来源顺序执行检查并引用证据
4. 目标任一否/未知先补足；实施Q1为是时接受合理解释
5. 不合规转影响评估和处置，批准不能由生成器或审计员代行

## 来源检查项与顺序分支

G184 §6.2保留简版问题；下表按G186表15-1/15-2的详细分支操作。`unknown`与`not-reached`是项目记录状态，非原表选项。

### 目标九问

| 顺序 | 问题 | 否或待确认时的动作（实施Q1例外见本行） |
|---|---|---|
| 1 | 是否正确识别利益相关者？ | 接触适合范围的授权利益相关者 |
| 2 | 是否考虑上层约束与指导？ | 补上层约束；冲突由上层利益相关者决定豁免或执行 |
| 3 | 适当SME是否同意事实和解释？ | 咨询SME，分歧报告为置信度局限 |
| 4 | 约束/指导是否与视图及模型分析一致？ | 重作一致视图 |
| 5 | 视图是否回应关注点并与模型分析一致？ | 重作回应关注点的视图 |
| 6 | 利益相关者是否理解价值和实现不确定性？ | 补价值及不确定性说明并回访 |
| 7 | 是否理解达成目标所需工作及风险？ | 补工作量和风险说明并回访 |
| 8 | 是否理解置信度限制？ | 补置信度限制说明并回访 |
| 9 | 利益相关者是否批准视图？ | 由利益相关者决定重做或取消；未批准不得发布为批准目标 |
### 实施七问

| 顺序 | 问题 | 否或待确认时的动作（实施Q1例外见本行） |
|---|---|---|
| 1 | 变更是否合理解释目标架构约束与指导？ | 合理解释即接受为合规；若仍有问题通过变更架构处理。否则进入影响评估 |
| 2 | SME是否同意影响评估的事实与解释？ | 咨询SME，保留冲突和置信度限制 |
| 3 | SME是否同意执行/临时豁免/变更目标建议？ | 咨询SME并披露建议分歧 |
| 4 | 视图是否反映影响评估及支撑模型？ | 重作与模型分析一致的影响视图 |
| 5 | 利益相关者是否理解评估置信度局限？ | 补充并解释局限 |
| 6 | 是否理解预期价值和不确定性变化？ | 补充同口径价值影响 |
| 7 | 利益相关者是否批准处置建议？ | 批准才实施；执行需纠偏证据，临时豁免需到期复评，改目标需重新治理 |

G186实施Q1为是时直接接受合规，Q2至7记为未进入分支；若Q1为否则继续影响评估。目标九问必须顺序获得足够证据。生成这些记录不等于取得利益相关者批准。
