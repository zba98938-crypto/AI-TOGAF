# EA服务与ADM证据映射

主责 `togaf-ea-capability`；既有制品 `ea-service-catalog` 的专用规范 `ea-service-adm-evidence-map`。

必要输入：本页字段对应的原始业务观察、来源、范围和时点。缺关键证据时保留unknown及缺口，不作通过判断。

## 字段与语义

| 字段 | 含义 |
|---|---|
| service | 服务目录项 |
| ADM_phase | 项目使用阶段，可多记录而非唯一归属 |
| project_activity | 服务在该阶段支持的活动 |
| output | 具体交付或决策输入 |
| owner | 责任角色 |
| mapping_origin | project-observation/project-proposal/source-verified区分 |
| evidence_detail | 项目或来源定位 |
| source_mapping | 原图映射核实结果；未知不填不适用 |

## 分析

1. 先明确服务输出与消费者决策
2. 由项目活动确定使用阶段
3. 分别登记来源映射和项目映射
4. 未知原图格不推断不适用或唯一阶段

## 表示与检查

输出对象/完整属性表、所有有类型关系与证据。table输出不进入通用流程图，不等于对应来源图已通过两布局视觉验收。
- 每条映射有来源与目的
- 制定准则和执行评估分开
- 未知保持unknown
- 不得把项目安排伪称原图精确对应
