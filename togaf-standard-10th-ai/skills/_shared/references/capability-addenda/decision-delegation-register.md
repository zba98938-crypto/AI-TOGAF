# 决策授权与可逆性登记

主责：`togaf-implementation-governance`。决策问题：某类决策由谁、在何种边界内决定，何时需扩大参与或重新评审？

本能力包是来源正文的项目操作化规范。原指南没有规定的字段结构、枚举与校验规则均是本实现约定；不把它们称为 TOGAF 强制量表。完整案例均为虚构，审批与实施状态单独记录。

## 入口与输入

制品族 `decision-delegation-register`；默认规范 `decision-delegation-register-default`。视图实例应按范围/时间点给独立view_id。仅请求本工作产品时读取本页、指定原料与模型即可，无需生成其他制品。

- 决策范围和影响对象
- 参与人、权限与企业护栏
- 可逆性证据和回滚条件
- 组织采用的授权规则及批准状态

缺失关键输入标记draft和带ID缺口，停止对应通过判断；可以生成明确草稿，不能编造分数、批准、实现或事实。

## 元素、关系与字段

对象类型：guide:delegation_decision。对象ID在修改与两视图中稳定；显示名称可重复但需不同ID/范围。

| 字段 | 语义与要求 |
|---|---|
| decision_scope | 授权适用的具体决定、对象和影响边界；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| delegation_level | G210引用的Management3.0名称之一；只作词汇，具体权责另列；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| framework_origin | 外部方法归属与项目操作化说明，防止冒充TOGAF独创；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| authority | 谁在听取谁意见后做何种决定的项目明文约定；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| participants | 需要参与当前决策的团队或角色，不仅列被通知人；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| reversibility | reversible/irreversible/unknown；对整个决定结果而非单一技术动作判断；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| reversibility_evidence | 支持可逆性判断的业务与技术证据或明确缺口；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| rollback_plan | 回滚方式、条件与未覆盖部分；不可回滚明确not-available；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| guardrails | 授权不能突破的企业/项目约束及范围；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| authorization_status | 授权安排本身的proposed/approved等状态；批准需要真实证据；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| review_trigger | 哪些范围、消费者、规则或恢复条件变化要求复评；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| decision_result | 当前决定或建议及未决条件，不由授权级别自动推导；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| source_refs | 支持本条业务内容的来源ID列表，区别指南定义来源；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |

关系：本表的外部引用字段以稳定ID链接相应待办、冲刺、描述或来源；参见完整包model.json。引用不是组成或因果箭头，不可据相邻位置推断。

## 分析步骤

1. 为具体决策划清范围、受影响方及护栏。
2. 记录reversible/irreversible/unknown及依据；未知不能默认为可逆。
3. 可选引用七授权名称tell/sell/consult/agree/advise/inquire/delegate，逐条用项目语言明确定谁决定、谁参与。
4. 不可逆或可逆性不明时明确更广群体及需补证据；不从数值等级自动推导批准。
5. 记录提案、批准证据与复评触发，授权状态与架构实现状态独立。

## 输出与表示

输出完整对象属性表、关系表、结论、证据、缺口及交付物视图引用。output_kind=table；不为表格强制绘制流程图。参考结构模式保持稳定字段顺序；适配模式可分节/分页，但每个必要字段和关系必须出现，缺项报ID。没有声称复刻原图。

## 评审

- 七名称来自外部方法；权责描述与组织约定一致
- 可逆有回滚条件与证据；unknown不当作reversible
- 不可逆决策有跨相关团队参与安排
- 无批准证据只能proposed，不实际执行
- 决策影响变化触发复评

误读：
- 七级不是TOGAF成熟度评分
- “高授权级”不代表更好
- 来源转引不等于已核实完整Management3.0规则
- 用户使用本技能不构成外部业务授权
