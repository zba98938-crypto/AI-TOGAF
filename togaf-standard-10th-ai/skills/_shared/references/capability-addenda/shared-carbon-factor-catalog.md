# 共享碳单位数据与因子目录

哪些单位数据可在什么边界、版本和单位下复用于环境评估？

依据：G242 §3.6.3表3-4。实际读过对应中文正文与既有逐节审计；本轮未重做英文/原图或外部标准核验。字段为项目操作规范。

## 输入与缺口

组织、服务、业务用途及所评估期间/生命周期边界；原始访谈、使用数据、供应商记录及稳定证据ID；适用目标、职责和组织自定决策规则；未知项显式登记。关键依据未知时给候选表、受影响ID与责任；不编造权重、阈值、估算、批准或实际完成。

## 字段

| 字段 | 含义 |
|---|---|
| name | 单位数据/因子 |
| data_kind | 活动强度、设备足迹或电力因子等，不全部称排放因子 |
| value | 原始值；不静默插值 |
| unit | 原始单位与分母 |
| period | 适用/观察期间 |
| geography | 地区/设施/能源结构 |
| lifecycle_boundary | 制造、运行或组合边界 |
| applicability | 机型/服务/分配范围 |
| allocation_basis | 是否含PUE及服务分配依据 |
| source_version | 来源版本和更新日期 |
| source_locator | 原料/供应商/计算记录定位 |
| quality | 测量/估算/未知及不确定性 |
| reuse_limits | 不可跨何种范围/单位/期间复用 |

## 分析步骤

1. 收集原始单位数据和来源，不把计算结果当原始因子
2. 声明机型/服务/地区/期间与生命周期边界
3. 核实单位分母、分配与PUE包含情况
4. 登记版本、质量和适用限制
5. 更新时保留旧版及引用该版的评估，禁止静默替换历史计算

## 修改与反例

修改：FC-03发布v2地点因子0.35，v1仍存在。预期：新增版本、适用期与变更理由；既有v1引用不被覆盖。

反例：因子缺单位/期间/来源或把制造kgCO2e/台当年度值。预期：carbon-data-metadata-gap或boundary-unit-conflict。

- 表3-4非穷尽，不把五类当数量上限
