# 冲刺DORP记录

主责：`togaf-change-value`。决策问题：本冲刺是否达成目标、学到什么、哪些工作需要回流或进入下一次规划？

本能力包是来源正文的项目操作化规范。原指南没有规定的字段结构、枚举与校验规则均是本实现约定；不把它们称为 TOGAF 强制量表。完整案例均为虚构，审批与实施状态单独记录。

## 入口与输入

制品族 `dorp-record`；默认规范 `dorp-record-default`。视图实例应按范围/时间点给独立view_id。仅请求本工作产品时读取本页、指定原料与模型即可，无需生成其他制品。

- 明确冲刺目标与所选待办
- 演示观察及成果证据
- 未完成项/新需求
- 回顾及下一步行动责任

缺失关键输入标记draft和带ID缺口，停止对应通过判断；可以生成明确草稿，不能编造分数、批准、实现或事实。

## 元素、关系与字段

对象类型：guide:dorp_record。对象ID在修改与两视图中稳定；显示名称可重复但需不同ID/范围。

| 字段 | 语义与要求 |
|---|---|
| sprint_ref | DORP所审阅冲刺稳定ID；在独立调用时作为明确外部引用；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| goal | 整个冲刺的可验证目标；不能由选中事项标题自动代替；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| demo | 逐项实际展示内容、证据和未展示/失败观察，不是完成自报；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| outcomes | 相对于原目标的结论、完成/未完成集合及理由；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| retrospective | 对做法及结果的回顾，区分观察与推测根因；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| next_plan | 下一步建议的ID、行动、责任、时间和状态，不能冒充已批准承诺；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| returned_to_business_backlog | 未完成项回流业务待办的原始ID列表；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| new_backlog_requests | 新提出但可能尚未澄清/估算的需求，不默认承诺；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| review_at | DORP的评审时点，用于保留历史目标判断；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |
| history | 按观察时间保留状态/结论与证据的历史，不由后续结果覆盖；必填有来源的具体值或显式unknown/待确认，并在缺口中登记；空值不能伪装完成。 |

关系：本表的外部引用字段以稳定ID链接相应待办、冲刺、描述或来源；参见完整包model.json。引用不是组成或因果箭头，不可据相邻位置推断。

## 分析步骤

1. 先固定本次冲刺目标和评审时点，不因结果不好而改写目标。
2. 按Demo记录实际展示和未展示内容；按Outcome核对目标与成果。
3. 按Retrospective解释偏差与可改进做法，不将推测当根因事实。
4. 按Planning形成有责任人与依据的下一步建议；未完成项回到业务待办。
5. 新需求先登记澄清，不自动承诺下一冲刺；保留历史与后续补充。

## 输出与表示

输出完整对象属性表、关系表、结论、证据、缺口及交付物视图引用。output_kind=table；不为表格强制绘制流程图。参考结构模式保持稳定字段顺序；适配模式可分节/分页，但每个必要字段和关系必须出现，缺项报ID。没有声称复刻原图。

## 评审

- Demo/Outcome/Retrospective/Planning四项分别存在
- 有强制冲刺目标，结论对应同一目标
- 完成和未完成集不交叉，未完成集全部回流
- 未展示或缺证据的成果不标完成
- 后续完成不能倒改原冲刺历史失败

误读：
- DORP不是只写会议纪要或四个空标题
- 不能把演示次数代替价值
- 下次计划是建议，非批准或实际已完成
