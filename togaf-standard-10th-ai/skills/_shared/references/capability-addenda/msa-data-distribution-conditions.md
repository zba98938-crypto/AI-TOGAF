# MSA数据分布、分片与批次条件表

主责 `togaf-information-data`；既有制品 `data-dissemination-diagram` 的专用规范 `msa-data-distribution-conditions`。

必要输入：本页字段对应的原始业务观察、来源、范围和时点。缺关键证据时保留unknown及缺口，不作通过判断。

## 字段与语义

| 字段 | 含义 |
|---|---|
| data | 逻辑数据内容，副本不自动成为另一实体 |
| store | 物理或逻辑存储身份 |
| owner_service | 数据责任服务 |
| replica_role | 主控/副本/缓存用途 |
| shard_strategy | 分片键、规则与依据或明确不分片 |
| external_provider | 外部供数责任方 |
| transfer_direction | 源→目标的数据方向 |
| frequency_trigger | 批频次/触发、失败动作 |
| freshness_limit | 最大陈旧性与超限处理 |
| security | 属性/实体密级及声明量表 |
| retention | 保留与删除/恢复范围 |
| migration | 初始与增量迁移方式 |
| access_rule | 接口访问与数据库边界 |

## 分析

1. 识别数据责任与外部离线供数
2. 按响应/可用要求选副本/缓存与分片
3. 声明触发、陈旧性、安全与生命周期
4. 核查数据流与运行独立性冲突

## 表示与检查

输出对象/完整属性表、所有有类型关系与证据。table输出不进入通用流程图，不等于对应来源图已通过两布局视觉验收。
- 每副本有源与陈旧性处理
- 批流标频次或触发
- 实体密级不能低于属性最高
- 不默认跨库共享
