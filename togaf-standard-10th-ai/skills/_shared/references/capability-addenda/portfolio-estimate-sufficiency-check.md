# 组合估算充分性检查

继续细化是否仍有足够收益，预算决策是否已有充分依据？

依据：G186 §8.4.2。字段结构与状态编码是项目操作规范，原始指南不随运行读取。

## 输入与缺口

范围、五维语境、所用目标与交付物版本；原始计划/访谈/验收/估算及来源ID；组织授权和容差规则；缺失时不代推。关键依据未知时给候选表、受影响ID与责任；不编造权重、阈值、估算、批准或实际完成。

## 字段语义

| 字段 | 含义 |
|---|---|
| name | 充分性检查项 |
| sequence | 来源十问顺序 |
| question | 检查问题 |
| finding | 事实/回答而非统一分数 |
| evidence_refs | 材料ID |
| rule | 源指南建议或项目规则的归属 |
| calculation | 如适用显示数据和计算过程 |
| limitation | 缺口/时效/不可比限制 |
| next_action | 继续调查或提交决策者的建议 |

## 分析步骤

1. 逐项回答来源十问，保留第6问负向语义和第10问数量
2. 比较各轮同范围估算与覆盖计数
3. 只在项目明示公式/应急参数时计算第8/9信号
4. 指出风险、时效和关键未知对建议的影响
5. 给停止/继续调查的有据建议，不自动批准预算

### 组合估算充分性十问

原始材料（历史材料已清理）组 `sufficiency`。覆盖比3降到2，估算变化6%小于项目10%缓冲，两项文献收益递减信号均达到；建议转预算决策，不将估算当承诺或权重评分。

## 修改与反例

修改：本轮估算106万改125万，覆盖比从2改4。结果：估算变化25%超过缓冲、比值未下降；收益递减信号均未达到，继续针对高不确定项调查。

反例：缺应急系数却生成10%默认值。结果：missing-project-contingency。

## 质量与追溯

- 第6问“有无担忧”与其他问不是同方向，禁止全是即通过
- 第10问是数量，不能硬转是/否
- 8/9为该指南收益递减信号，项目缓冲和公式须明确来源
- 缺范围可比性或深度分母为零时保留未知

执行证据（历史材料已清理）分别记录模型、生成、修改、反例及表内表达。表格不进行图形视觉验收。工程执行不能替代业务审批和独立业务审查。

## 来源十问

1. 每主题工作包按能力连续谱分类且不混保持/改进？
2. 依赖与级联影响获决策者和实施者认可？
3. EA全景探索是否连续？
4. 风险缓解与控制是否加入组合？
5. 各主题兼顾运营卓越与适用性？
6. 是否存在时效性担忧？
7. 是否已有粗略估算与应急系数？
8. 覆盖广度增长/深度增长比是否递减？
9. 相邻迭代估算差异是否小于应急系数？
10. 多少工作为一次性转型执行？

第8/9仅提供该指南收益递减信号；第6问有担忧可能要求重新调查，第10问记录数量，不得加权合成为通用合格分。
