# 不合规影响与处置登记

对已证实偏差应强制执行、临时豁免还是重审目标？

依据：G186 §15.2.2表15-2；G184 §6.2、§6.5。源文提供方法与参考，字段和状态编码为项目操作规范。公开官方核验以覆盖索引为准。

## 必要输入与缺口

范围和五维语境；原始访谈/计划/测量及定位；授权角色和适用目标版本。逐项登记缺口；未知不等于否或零。缺授权、原口径、时点或关键证据时只能候选，不自动批准、通过或核算。

## 字段与语义

| 字段 | 含义 |
|---|---|
| name | 处置事项 |
| subject | 实施对象与目标版本 |
| violated_spec | 违反的规格ID |
| original_value_basis | 与批准目标一致的范围/期间/量测方法 |
| evidence_refs | 偏差证据 |
| impact | 价值、风险和置信度影响 |
| options | 执行、临时豁免、变更目标三个选项及影响 |
| recommendation | 架构师候选建议 |
| decision_owner | 授权利益相关者 |
| decision | 已决定或待决定；与建议分开 |
| expiry | 临时豁免有效期 |
| review_date | 复评日 |
| review_owner | 复评责任人 |
| follow_up | 纠偏/复评/目标重批及其证据 |

## 从原料到结论

1. 核对目标约束是否确被违反而非实现偏好不同
2. 按开发目标时同一价值/风险口径分析影响
3. 请SME核实事实、列出三种处置及取舍
4. 向授权利益相关者提交建议，记录其决定
5. 临时豁免设置期限、复评责任与日期；执行需纠偏证据；改目标重走目标批准

### 不合规影响与处置登记

原始材料：`disposition`（历史材料已清理）。

沿原P95/城西站口径分析三项选择，建议有期限豁免；尚未获得授权批准，不能把建议写作已豁免。

完整输入、输出和双布局执行索引见验收记录（历史材料已清理）。`artifact_id=non-compliance-disposition`，`profile_id=non-compliance-disposition-default`，示例 `view_id=v-non-compliance-disposition-default`。

## 修改与反例

修改：把建议改为强制执行，计划10工作日修复。预期：新增纠偏验证任务，豁免期限不再充当授权；目标60秒保持。

反例：临时豁免没有到期日或复评责任。应有结果：waiver-needs-expiry-review-owner拒绝完成。

## 评审与追溯

- 永久豁免实质改变目标，必须转目标变更
- 更换指标/范围来获得通过会使评估失效
- 建议、批准和落实是三个独立事实
