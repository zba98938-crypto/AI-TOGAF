# 价值实现评估

目标价值是否实际实现，差距是否需要H阶段发起新工作？

依据：G184 §10.1.7、§10.1.9、§11.4；G186 §8.7、§10.4、§14、§15.2.3。源文提供方法与参考，字段和状态编码为项目操作规范。公开官方核验以覆盖索引为准。

## 必要输入与缺口

范围和五维语境；原始访谈/计划/测量及定位；授权角色和适用目标版本。逐项登记缺口；未知不等于否或零。缺授权、原口径、时点或关键证据时只能候选，不自动批准、通过或核算。

## 从原料到结论

1. 明确价值主张、接收方、责任人与观察期间
2. 锁定同范围同单位的基线/目标和计算依据
3. 收集运营实际及证据，识别同时发生变化
4. 逐指标比较目标差距并解释不确定性与归因限制
5. 由组合/运营持续复评，必要时创建H变更/新工作请求

## 修改与反例

修改：人工签收实际工时620改为480且保持口径。预期：观察改善320小时，目标超额20小时；归因仍未证实，晚送率仍未达成。

反例：实际为全部站点而基线只有城西站。应有结果：incomparable-measurement-scope；停止差额计算。

## 评审与追溯

- G检验实施合规，H检验价值持续性及新变化，不能互相替代
- 不同范围、业务量、期间口径须归一化有依据或保持不可比
- 没有来源或明确项目规则不得计算ROI、权重或宣称收益归因
- 实际未测不能用0代替；计划收益不等于已实现价值
