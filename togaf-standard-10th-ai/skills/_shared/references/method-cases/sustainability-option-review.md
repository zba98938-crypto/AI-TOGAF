# 在减排、服务与设备寿命之间保留方案权衡

## 决策与原始业务资料

选择服务器替换或延寿改进，记录环境债务与复评条件。

|证据 ID|原始材料|
|---|---|
|sus-1|项目环境记录：现设备运营每年460kgCO2e；替换方案新增运营69kgCO2e/年、新设备制造1200kgCO2e；现设备制造排放属于历史，不因退役从本期抹去。所有数值为虚构估算。|
|sus-2|延寿方案运营降至300kgCO2e/年，改造新增制造50kgCO2e；两个方案的用电边界一致，但制造估算使用供应商资料，置信度较低。|
|sus-3|业务要求支持相同业务量并满足恢复目标；替换的性能验证通过、延寿方案尚未完成负载测试。委员会尚未约定生命周期评估年限、折算或单一总分规则。|

## 来源规则与项目规则

1. **来源方法**：方案评估需覆盖业务贡献、环境影响、措施、债务与持续复评；原图中的数值矛盾应单独登记而非静默修正。
2. **来源方法**：不同生命周期边界的排放不得未经约定跨期间求和。
3. **项目规则**：本案按运营与制造分列，**不跨期间求总量**——这是项目约定。
4. **项目规则**：不能把退役资产的历史制造排放当作本期负排放；无评估年限与折算规则时不给单一总分。

**来源依据**：`references/capability-addenda/sustainability-capability-assessment.md`。

## 转换与推理

1. **先固定边界，再算差值**。`sus-2` 明说"两个方案的用电边界一致"，这是可比的前提。三个数在同一口径下才可相减：

   | 量 | 替换 | 延寿 | 说明 |
   | --- | --- | --- | --- |
   | 运营年排放 | 69 | 300 | 同边界，可比 |
   | 现设备运营 | 460 | 460 | 共同基线 |
   | 运营年变化 | 69 − 460 = **−391** | 300 − 460 = **−160** | 负号表示下降 |
   | 新增制造 | 1200 | 50 | 供应商边界可比性尚待核实，低置信度 |

2. **不许把运营收益与制造投入合成一个"总节省"**。−391 kg/年 是**每年**的量，1200 kg 是**一次性**的量，两者单位不同（kg/年 vs kg）。相加必须先乘年限，而 `sus-3` 明说委员会**尚未约定评估年限**。因此本案例**不做这个加法**，只并列。

3. **历史排放不进本期账**。`sus-1` 说现设备制造排放属于历史。**退役不产生负排放**——把已发生的排放记为"避免"，等于用会计手法制造减排。这条是本案例最容易出错的地方。

4. **业务约束先筛，环境数据后比**。`sus-3`：替换方案性能验证通过，延寿方案**尚未完成负载测试**。因此：
   - 不能宣称延寿满足业务要求
   - 也**不能**因为延寿制造排放低（50 vs 1200）就推荐延寿
   
   两个方向都不成立：**业务未验证不能推环境更优，环境更优不能推业务可用**。

5. **权衡要写成可读的对立项**：
   | 维度 | 替换 | 延寿 |
   | --- | --- | --- |
   | 运营改善 | 大（−391） | 小（−160） |
   | 前置制造 | 高（1200） | 低（50） |
   | 业务性能 | 已验证 | **未知** |

   三行没有共同单位，**不能压成一个综合分**。

6. **债务登记到人**。`ENV-DEBT-1`（供应商制造数据待核验）归设施负责人（候选责任分配，待接受）；`ENV-DEBT-2`（延寿性能待测）归性能负责人（候选，待接受）。两者都需在**下一次采购评审前**补齐，而不是"以后再说"。

## 修改演练

**情景一：委员会明确采用三年、相同服务量、无折算、同一 kgCO2e 边界**。此时才可做项目敏感性情景：
- 替换：1200 + 3 × 69 = **1407**
- 延寿：50 + 3 × 300 = **950**

   在**这个特定情景**下延寿总量更低。但这不是永久优劣，翻转点可算出：令 `1200 + 69n = 50 + 300n`，得 `n = 1150 / 231 ≈ 4.98`。**评估年限超过约 5 年时，替换方案的累计排放反低于延寿**（10 年：1890 vs 3050；20 年：2580 vs 6050）。**结论对年限高度敏感，所以年限必须由委员会给，不由分析者选。** 且业务性能门槛仍须满足——延寿未测，不能仅凭排放入选。

**情景二：延寿完成负载测试且通过**。`ENV-DEBT-2` 关闭，延寿成为业务可行候选，此时才进入真正的两者权衡。

**情景三：供应商数据核验后制造排放大幅修正**。`CMP-1` 的制造数字全部变化，上述敏感性情景需重算。**运营差值不受影响**（不依赖供应商数据），但综合比较可能翻转。

**影响范围**：情景一新增一个带明确前提的敏感性计算，不改变无前提时的"不给总分"结论；情景二关闭 `ENV-DEBT-2`；情景三改变制造侧数字。三种情形下 `CMP-3`（历史不计负排放）不变。

## 反例与输入不足

- **错误做法**：把来源中的 −390 静默改写为 −391。改写会丢失来源冲突。预期 `measurement-basis-gap`。
- **错误做法**：以抵消积分直接抵减新增设备制造排放，未声明任何方法依据。预期 `unsourced-maturity-rating`。
- **错误做法**：在生命周期评估年限与折算规则未约定时给出单一总分。无规则即无总分。预期 `measurement-basis-gap`。
- **错误做法**：把 −391 kg/年 与 1200 kg 直接相加并称"总节省809"；即使误当同单位，算术和也是+809而非−809。单位不同（/年 vs 一次性）。预期 `measurement-basis-gap`。
- **错误做法**：因现设备退役，就把其历史制造排放记为"避免排放"抵减替换方案。历史排放不因退役消失。预期 `measurement-basis-gap`。
- **错误做法**：因延寿制造排放低（50）就推荐延寿，忽略其性能未测。环境数据不能替代业务验证。预期 `approval-without-evidence`。
- **错误做法**：自行选定 3 年评估年限以得出"延寿更优"，并把它当作客观结论。年限须由委员会约定。预期 `unsourced-maturity-rating`。

**输入不足**：委员会尚未约定评估年限、折算方式与单一总分规则，因此两方案不能排名。`sus-2` 的制造估算使用供应商资料且置信度较低，`ENV-DEBT-1` 保留。延寿方案负载测试未完成，`ENV-DEBT-2` 保留。材料未给电价与设备残值，故不做成本比较。

- 核对两个方案的用电边界一致，制造估算均使用供应商资料并标注为低置信度。
- 核对运营差值（−391、−160）可复算，且负号语义一致（下降）。
- 核对现设备的历史制造排放**未**因退役从本期抹去，也未计为负排放。
- 核对 kg/年 与 kg 两种单位被显式区分，未直接相加。
- 核对运营与制造分列呈现，未在未约定评估年限时跨期间求总量。
- 核对来源中的数值矛盾（−390 与 −391）被单独登记保留，未静默取其一。
- 核对业务性能与环境表现两个方向都未被单方面当作结论。
- 核对未给出单一总分或排名，理由（年限、折算方式、总分规则未约定）已写明。
- 核对敏感性情景的年限由委员会给定，且明确"不代表永久优劣"。
- 核对两项环境债务均指派了责任人与补齐时点。
