## 来源规则与项目规则

1. 来源方法（G238）：模型运营监控需覆盖准确性、输入分布、技术、安全、使用五类，单一准确率不足。
2. 来源方法：重训不等于可自动投产，需版本测试与业务复核。
3. 项目规则：**无阈值不判达标**（`bim-3`）；只能报观测值，不能报"通过/不通过"。
4. 项目规则：`bim-1` 的影子状态意味着输出仅供分析，不得进入客户承诺链路。

## 转换与推理

1. **度量定义**：`bim-2` 定义的是"绝对差中位数（分钟）"。这是**连续量**，不是比率，因此不使用"准确率"表述。
2. **当前状态**：`bim-3` 说无实际值与阈值。因此：
   - 可以定义度量口径；
   - 不能计算当前值；
   - 不能判断是否达标。
3. **五类监控项的落法**：

| 类别 | 具体项 | 现状 |
| --- | --- | --- |
| 准确性 | 绝对差中位数 | 口径已定，值未知 |
| 输入分布 | 故障类型标签质量 | 未知（`bim-4`） |
| 技术 | 作业/数据失败 | 已知会先停建议 |
| 安全 | 数据访问范围 | 未在材料中说明 |
| 使用 | 人工改判次数 | 需收集 |
4. **处置规则**：失败即停建议并转人工（`bim-6`）；重训后需版本测试 + 业务复核，不自动投产。
5. **影子边界**：因 `bim-1`，即使模型输出进入看板，也不得触发对客户的时长承诺。

6. **连续量与比率是两种度量，不能互换表述**。`bim-2` 定义"绝对差中位数（分钟）"，这是**连续量**。因此：
   - 可报"中位绝对差 X 分钟"
   - **不可报"准确率 Y%"**——准确率需要一个"算准"的判定阈值，而阈值未定
   
   同一批数据，用连续量描述是事实，用比率描述需要额外约定。

7. **无阈值时的正确表述是"仅报观测值"**。`bim-3` 说没有实际值也没有合格阈值。此时输出必须是：
   - 度量口径（口径已定）
   - 观测值（当前无）
   - **不写"通过/不通过""达标/未达标"**

   这不是保守，而是**避免用一个未定义的阈值给结论**。阈值一旦由业务给出，判定才成立。

8. **五类监控项缺一不可，单一准确率不足**。来源方法明说需覆盖准确性、输入分布、技术、安全、使用五类。本案的落法：

| 类别 | 缺失后果 |
| --- | --- |
| 准确性 | 不知道预测好不好 |
| 输入分布 | 不知道故障类型漂移，模型可能对某类系统性偏差 |
| 技术 | 作业失败时仍在出建议，风险外溢 |
| 安全 | 数据访问范围不明，可能越权 |
| 使用 | 不知道人工改判了多少次，无法判断实际价值 |

   其中**"使用"类最容易被忽略**：模型"跑起来了"不等于"被用了"，更不等于"改对了"。

9. **影子试点的边界必须硬性**。`bim-1`：影子试点供分析，**不自动给客户承诺**。因此即使模型输出进入看板，也不得触发：
   - 对客户的时长承诺
   - 自动排程
   - 服务等级约定

   影子期的作用是**积累对照数据**，不是提前投产。

10. **重训的准入门槛**。`bim-6`：重训须版本测试与业务复核，**不能自动投产**。这条与"失败即停"配套：停是止血，重训是复原，**复原也要过门**。

## 修改演练

**情景一：设定阈值（如中位绝对差 ≤ 15 分钟）**。此时只补齐判定规则，仍无实际观测值，**不能立即判达标；阈值必须有裁决记录与依据**——不能由模型负责人单方设定。阈值来源可以是业务可接受度、历史基线或服务水平，需写明是哪一种。

**情景二：标签质量被确认不可靠**。输入分布监控失去意义（监控的是错标签的分布），需检查标签在训练、分组和评估中的用途；可先定义度量，待合格数据后再计算与解释效果。否则准确性问题会被错误归因到模型，而真实原因在数据。

**情景三：发现作业失败但模型仍在出建议**。应触发 `bim-6` 的"先停止建议回人工"。**这是硬规则，不是建议**——失败期间的建议会污染影子期的对照数据。

**情景四：重训完成，版本从 v0.1 升 v0.2**。需版本测试 + 业务复核后才可进入影子期。**不能自动投产，也不能跳过影子期直接上线。**

**影响范围**：情景一补齐规则，仍待实测才能判定；情景二改变监控重点与归因方向；情景三触发停止规则；情景四决定新版本准入。四种情形下"影子期不给客户承诺"的边界不变。

## 反例与输入不足

- **错误做法**：没有阈值就宣布模型"达标"或"表现良好"。无阈值不判达标。预期 `approval-without-evidence`。
- **错误做法**：把"绝对差中位数 12 分钟"改写成"准确率 85%"。连续量转比率需要"算准"的判定阈值，阈值未定。预期 `measurement-basis-gap`。
- **错误做法**：只监控准确性，忽略输入分布、技术、安全与使用四类。单一指标不足。预期 `missing-evidence`。
- **错误做法**：影子期把模型输出写进客户可见的时长承诺。影子期仅供分析。预期 `approval-without-evidence`。
- **错误做法**：作业失败期间仍继续输出建议，理由是"影响不大"。`bim-6` 要求先停。预期 `missing-evidence`。
- **错误做法**：重训完成后直接投产，跳过版本测试与业务复核。预期 `approval-without-evidence`。
- **错误做法**：因模型已部署就认为"已被使用"。部署与使用是两件事，使用需人工改判等记录。预期 `missing-evidence`。

**输入不足**：`bim-3` 说无实际值与阈值，因此本案例不给达标结论。`bim-4` 未给标签质量的具体问题，输入分布监控无法细化。材料未说明安全类监控的具体项（访问范围、脱敏规则），该类别只能记为"未在材料中说明"。`bim-5` 未给人工改判的记录方式，使用类指标无法计算。
