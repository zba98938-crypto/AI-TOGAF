# 核心包范围

2026-11-05按用户要求清理历史生成产物，只保留可复用能力与本机一套运行依赖。来源摘要、243份便携图表解释、字段检查、模板、方法教学案例和原始代码保留；64方法不都具有确定性计算器。

`reviews/`、旧测试产物、旧注册表、离线npm缓存、验证缓存和历史图像/数据库不随核心包保存。项目根目录的`tests/`重新纳入可复用测试源码及小型夹具；它在`skills/`之外，运行技能无需复制。原文档对已清理材料的引用改为普通历史说明，不再是可点击的产物入口；旧执行结论不能当作当前产物存在的证明。

输入业务事实、来源、模型、评审与批准证据由项目另行提供。新生成内容应放在技能目录之外，按需生成、核对manifest、来源、警告和实际图像。标准来源核实和业务接受仍需独立评审。

当前使用入口见[集合说明](../../README.md)。维护/历史重放脚本保留源码，但依赖的历史案例与报告未随包提供，执行时需明确恢复或重建输入，不应据其默认路径推断历史资料仍存在。

当前回归从实际注册表和案例构建输入，在技能目录外生成新的运行证据；空测试发现、缺浏览器或缺历史数据有明确状态及非零退出码。批次证据v2区分源码与运行目录，外部输入保存带哈希的快照；v1历史证据仍可读取验证。生成成功、算术通过及文本几何通过均不自动授予专业或业务验收。
