## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 待解决业务问题
2. 业务与技术环境
3. 人类及计算参与者
4. 期望结果和成功度量

### 建议形成的输出

1. 经过验证的业务场景
2. 参与者角色与交互模型
3. SMART目标与业务需求
4. 支持方案取舍的评价记录

### 应用步骤

1. 识别并排序问题，构造环境和参与者模型
2. 把预期结果写成可检验目标，补参与者职责、前置条件及服务质量
3. 通过规划、收集、分析、记录、评审迭代形成共识
4. 在需要需求的ADM阶段复用场景，按适用性停止无效细化

### 决策与验收问题

1. 场景是否解决高价值问题
2. 参与者职责和关键交互是否完整
3. 预期结果是否可测
4. 权重、评分尺度和偏好方向是否明确
