## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 现有架构实践和证据
2. 所选成熟度模型及版本
3. 评价范围和组织目标
4. 评分权重及报告规则

### 建议形成的输出

1. 按维度的成熟度评价
2. 薄弱环节和改进候选
3. 周期性评估基线
4. 评分方法与局限记录

### 应用步骤

1. 选择并裁剪适合组织的成熟度模型
2. 逐项收集实践证据而非仅看文档存在
3. 按等级锚点评价各架构要素
4. 区分加权成熟度与各级达成比例，并据差距安排改进

### 决策与验收问题

1. 评价依据是否反映真实实践
2. 量表版本和权重是否公开
3. 改进是否针对薄弱环节
4. 是否把示例模型误写成全局唯一规范
