## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 业务词汇及关键名词
2. 业务能力和价值流
3. 组织单元及信息交换
4. 现有数据模型与业务语义

### 建议形成的输出

1. 信息概念目录和定义
2. 信息概念间关系
3. 信息—能力/组织/价值流映射
4. 到概念数据模型的可追溯输入

### 应用步骤

1. 从业务关心的名词识别信息概念并核对含义
2. 给信息概念类型、定义及关系，保持业务语义
3. 关联能力、价值流、组织及信息流
4. 在C/D阶段把可表示的部分转成数据模型，保留不能简化为字段的信息

### 决策与验收问题

1. 概念是否业务真正关心
2. 名称同义或多义是否明确
3. 主观与非结构化信息是否被遗漏
4. 数据表示是否仍可追溯业务含义
