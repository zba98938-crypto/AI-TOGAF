## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 战略方向
2. 产品价值与需求
3. 架构范围和粒度
4. 现有能力及迭代约束

### 建议形成的输出

1. 战略/分段/能力级架构
2. 架构与产品待办关联
3. 过渡架构及能力增量
4. 协作和治理安排

### 应用步骤

1. 区分架构域与详细程度，建立战略上下文
2. 以适用的分段架构界定产品特性及非功能要求
3. 规划可独立提供价值的过渡状态和能力增量
4. 迭代验证问题、设计和实施，保持跨域产品协作

### 决策与验收问题

1. 每轮是否交付可识别价值
2. 细节是否足以支持当前决策
3. 过渡状态是否稳定可运营
4. 团队是否仍保持企业整体目标
