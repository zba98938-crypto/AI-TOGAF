## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 业务可持续政策
2. 系统及设备清单
3. 生命周期影响数据与排放因子
4. 供应商、使用量及目标约束

### 建议形成的输出

1. 数字可持续能力与政策
2. 生命周期环境核算
3. 基线、过渡和目标架构
4. 环境决策记录、治理与供应商数据契约

### 应用步骤

1. 界定生态边界、业务目标及环境影响指标
2. 建立包含制造、运行与外部服务的年度核算
3. 结合使用需求和基础设施分析改进候选
4. 把环境指标与决策、架构原则及审查流程关联
5. 通过ADM增量交付并跟踪环境债务及供应商信息

### 决策与验收问题

1. 是否包括制造及外包而非只看使用能耗
2. 系统边界与单位是否一致
3. 增效是否可能扩大不可持续活动
4. 决策阈值与权威是否明确
5. 源数据差异是否保留
