## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 业务变更待办
2. 当前架构与期望价值
3. 团队协作模式
4. 冲刺节奏及反馈能力

### 建议形成的输出

1. 最小可行架构MVA
2. 业务发展与方案增量协同
3. 演示、回顾和重新计划记录
4. 迭代治理及过渡架构

### 应用步骤

1. 选择适合组织的协作模式和冲刺边界
2. 从业务变更待办选择最高价值的可处理主题
3. 跨必要ADM阶段形成MVA并与方案团队共创
4. 演示获取反馈、回顾改进过程并更新后续待办

### 决策与验收问题

1. 每次冲刺是否产生有价值架构结果
2. 业务/架构/方案增量是否对齐
3. 依赖能否在冲刺或过渡架构内控制
4. 治理是否仍验证预期业务结果
