## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 架构工作请求
2. 业务论证及范围
3. 利益相关者验收条件
4. 所需视图、架构域和详细程度

### 建议形成的输出

1. 架构项目计划及工作分解
2. 批准的架构工作说明书
3. 阶段交付与验收记录
4. 目标架构、路线图和实施迁移计划交接

### 应用步骤

1. 定义项目最终产物和验收标准
2. 确定域、详细程度和视图后分解工作并配置责任
3. 形成进度资源计划并获赞助人批准
4. 按阶段执行、监控、处理偏差及决定继续或调整
5. 移交实施所需架构成果并总结经验

### 决策与验收问题

1. 交付物是否对应项目目标
2. 验收条件是否提前商定
3. 工作包责任与依赖是否明确
4. 阶段边界是否有继续/变更/终止决定
