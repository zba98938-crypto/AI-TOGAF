# 迁移与路线图：分析方法

适用 ADM：F。以下为跨指南综合及项目生成约定。

## 分析路径

1. 汇总成果、工作包和前置依赖。
2. 采集成本资源估算及可信区间。
3. 按明确决策准则比较排序。
4. 定义过渡、里程碑和切换。
5. 协调交付、回退与收益复评。

## 关键判断

排序须区分硬依赖与偏好，避免伪精确加权总分。跨域迁移协调数据、应用、技术和人员运营；切换必须考虑一致性、双运行、核对、故障恢复和服务连续性。路线图表达变革逻辑，实施计划承担资源排期与责任细节。

## 评审重点

依赖图可拓扑排序或明确解释循环；未获承诺的资源作假设；过渡状态可运营；回退准则可验证。
