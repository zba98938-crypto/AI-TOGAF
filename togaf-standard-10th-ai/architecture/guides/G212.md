## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 数字化业务战略
2. 采用范围与速度选择
3. 15项因素的现状证据
4. 缺失因素的后果和缓解策略

### 建议形成的输出

1. 采用方式与理由
2. 基础/影响/持续因素评价
3. 缺口及管理关注事项
4. 与ADM关联的渐进路线图

### 应用步骤

1. 先根据广度与速度选择并论证采用方式
2. 评估基础、影响和持续三类因素
3. 分析缺失因素的后果并制定缓解措施
4. 按企业上下文组织渐进实施，在ADM阶段验证基线与目标

### 决策与验收问题

1. 采用方式是否适合而非排名更高
2. 基础条件是否满足
3. 缺失因素是否有补救责任与时序
4. 问卷结果是否被擅自汇总为未定义分数
