## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 组织、业务模型与战略
2. 能力及应用目录
3. 价值流阶段
4. 能力实例的人员过程资源与绩效证据

### 建议形成的输出

1. 能力类型—实例关系
2. 实例与应用/过程/角色依赖
3. 差距和改进决策
4. 保持价值流可运行的能力增量

### 应用步骤

1. 整理组织、业务、应用和信息等目录并明确价值流
2. 将能力类型映射为特定阶段中的能力实例
3. 分析实例的参与者、资源、过程、应用和绩效缺口
4. 比较优化、合并、新建、退役方案
5. 按依赖组合增量，保持每个台阶上的价值流功能完整

### 决策与验收问题

1. 是否错误重复创建能力类型
2. 实例绩效是否有上下文和指标
3. 改进是否处理跨域依赖
4. 每个增量完成后价值流是否仍能运行

- [R007](../relationships.md#r007)：业务能力实例 → `enables` → 价值流阶段；使能实际阶段。
