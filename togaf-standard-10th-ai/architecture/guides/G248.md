## 项目应用建议

以下内容是基于本指南证据的建议。输入、输出与步骤不表示本项目已经具备或已经完成；采用前需要结合实际范围、约束和治理权责。

### 需要收集的输入

1. 变更目的、当前状态和约束
2. 变更风险与完整性要求
3. 上位架构
4. 目标KPI及交付期望

### 建议形成的输出

1. 变更画像与抽象层次
2. 选定ABB/SBB及关系
3. 视图、制品和交付物集合
4. 治理检查表和价值验收

### 应用步骤

1. 按变更环境选择快速、功能或稳健画像
2. 界定上下文和概念，并先说明可衡量结果
3. 建立逻辑构建块与相互作用，再映射物理实现
4. 选择适用视点及制品，并组织到交付物中
5. 安排实施治理并以契约、KPI及利益相关者价值确认成果

### 决策与验收问题

1. 选取的模型是否与问题匹配
2. 逻辑说明与物理实现是否可追溯
3. 交付物是否服务沟通和治理
4. 验收是否同时涵盖合约与业务价值
