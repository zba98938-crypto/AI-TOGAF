# Atlas：本地交互式架构平台

把共享模型、版本记录、校验和制品生成放进同一操作界面；不再只提供静态 SVG/PNG。

## 启动

在项目根目录执行：

```sh
python3 -B workbench/server.py --port 8765 --data-dir output/workbench-data
```

打开 <http://127.0.0.1:8765>。前端无需 npm 构建、CDN 或额外字体服务；后端依赖使用当前 Python 环境与唯一 skills 包的依赖。更换端口或 `--data-dir` 可建立独立本地工作空间。

## 操作闭环

1. **创建 / 导入**：从现有视点模板创建示例项目，或上传已有共享模型 JSON；也可通过“导入 UML/BPMN”载入 UTF-8 原生 XML。原生模型可以独立建立项目或加入现有草稿，服务保存原文及诊断版本。
2. **交互画布**：切换视图，搜索名称/ID/关系，按类型筛选；滚轮缩放、拖背景平移、拖节点保存布局，点击实体或连线查看详情及来源。
3. **编辑模型**：属性检查器修改名称、类型、属性 JSON、证据与确定性；新增/删除实体和关系。模型数据页可编辑完整记录、视图和完整模型。删除不会静默修复所有业务引用，保存前必须校验。
4. **校验 / 保存版本**：调用现有校验器，错误定位可见；模型、原生 XML 和独立布局保存为不可变快照。原生源码页分别显示输入错误、材料缺失和未覆盖能力。无效 XML 可以保存为诊断草稿，但不能生成或本地接受。并发基线冲突返回 409。
5. **版本对比 / 恢复**：比较两个已保存版本的模型字段、原生源码和布局；旧快照只能载入为新草稿，再保存成新版本。
6. **评审流**：将提交、意见、请求修改和本地接受绑定到指定版本。新模型版本不会继承旧版本的接受结论。评审记录不自动修改模型 `approval_status`。
7. **后台生成**：指定已保存版本，调用严格生成器，或导出原生 XML 与无损交换包；任务状态、失败原因、制品链接保留。原生预览复用同一任务队列。BPMN 保留显式 DI；缺少坐标时不会自动布图。UML 当前类图子集预览需显式勾选派生自动布局。已有 UMLDI 保留原文，预览报告未覆盖。交换成功和预览成功均不提升完整标准能力状态。

快捷键：`Ctrl/⌘ + S` 保存、`Ctrl/⌘ + Z` 撤销草稿、`Ctrl/⌘ + Shift + Z` 重做、`/` 搜索。输入框中保留原生撤销行为。

## 数据与安全边界

- 只绑定 loopback，本版本是**本机单用户平台**，不是对公网开放或具有 SSO/RBAC 的多人服务。评审作者为声明身份，不冒充认证签批。
- SQLite 和生成任务写到独立 `--data-dir`；不更改原 skills、导入源文件或旧 output 证据。
- 项目 JSON 继续兼容现有命令。原生模型的 `native.xml` 是该模型的权威数据；清单与预览从原文派生。画布坐标单独保存，不把位置、颜色和相邻关系推断成业务事实。
- 画布是明确标记的**关系交互投影**；专门矩阵、路线图、信任边界等专业表达仍由已有视点生成器负责。不能据此宣称严格建模语言认证或来源图等价。
- Canvas 每次最多绘制 600 个匹配实体、模型列表展示前 150 条。界面明确显示上限，可搜索缩小集合；完整数据保留，导出和校验不删减。
- 生成成功、结构校验通过、本地评审接受是不同状态；均不等于专业判断正确、真实业务验收或生产容量验证。
- 原 macOS native sandbox 浏览器故障不会被本界面的正常本地浏览器绕过或算作已解决。

后端接口与限制详见 `README-backend.md`。
