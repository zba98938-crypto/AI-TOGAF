## 数据约定

- `sections[].translation_zh`：完整的本节修订中文。`translation_mode` 区分沿用后校订、新译前置信息和仅标题。
- `sections[].source_units`：本节所有英文整理内容，包含精确文字、物理页码、内容数组下标、坐标、`source_block_ids`。没有臆造源文本块 ID；表格的详细单元格定位在独立结构化引用中。
- `sections[].semantic_rules`：人工编写的职责、范围、条件、例外、角色关系、情态和适用边界；每条均附精确原文片段与来源指纹。
- `sections[].corrections`：旧表达、新表达、理由、源文证据。不是全部标点或润色操作的字符级 diff。
- `sections[].structured_references`：完整技能矩阵、熟练等级和当前图片解析入口。G198 图像表未伪装成数字正文段落。
- `source_issues`：保留原文中的措辞含混、图注和术语不一致、算术差异；编辑解释与原文分开。
- `outline_coverage`：逐项列出原始书签的处置。未逐段对照的机构介绍、商标、作者、致谢、封面和导航等原文仍完整保存在 source 文档；其旧中文摘要未升级为已校订全译。G152/G203 已额外完整对照的前置资料在对应记录中明确列出。
- `validation`：实际来源一致性、覆盖和中文矩阵数值一致性的机械检查。`status=source-compared-revised` 表示本轮对照校订，不是独立翻译认证，也不自动改变图形审校状态。
- G176 的 `checklist_scope` 表明源文复选框均未勾选，项目状态为未评估；`example_scope` 表明第 9.3 节具体目标仅为候选示例。译文中的“已”以及示例百分比不能当成项目事实。
- `source_version` 在有来源依据时保留版本/取代关系。G18A 的版本更新证据位于物理第 4 页，属于源文元数据，未把整页法律声明计入正文中文审校。
- G203 第 2.3 节的 `structured_assessment_framework` 保存六等级、九要素、45 条有精确来源与中文的等级指标。等级 0 仅有整体描述，不补造九个评分项；两种评分方法的权重等参数在本指南未给出，当前组织全部状态为 `not-assessed`。
- G152 各有关子节的 `framework_location` 保存原文与中文的架构框架归属及引文，不把 ISM/ERM 归属误读为唯一 ADM 执行阶段。

证据中的路径以项目根目录为基准。生成 Markdown 时应根据最终输出位置计算链接；正文中的“读取本节 structured_references”应配合这些引用渲染为可点击入口。若要实现句级检索，需要继续建立精确中英对齐，不能把本次章节范围自动缩成句级证据。
